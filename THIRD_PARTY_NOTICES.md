# Third-party notices

All three OpenE2EE typefaces are licensed under the SIL Open Font License 1.1
and are self-hosted from package dependencies. No third-party font request is
made at runtime. The license text for each is included in the published package
under `brand/third-party/`; naming a license without shipping it does not
satisfy the OFL.

## Public Sans

`@fontsource-variable/public-sans` packages Public Sans, published by the
United States Web Design System, under the SIL Open Font License 1.1. License
text: `brand/third-party/PublicSans-OFL.txt`.

## Newsreader

`@fontsource-variable/newsreader` packages Newsreader, by Production Type,
under the SIL Open Font License 1.1. License text:
`brand/third-party/Newsreader-OFL.txt`.

## JetBrains Mono

`@fontsource-variable/jetbrains-mono` packages JetBrains Mono under the SIL
Open Font License 1.1. License text:
`brand/third-party/JetBrainsMono-OFL.txt`.

## Marks

The OpenE2EE mark is original geometry constructed on a 32-unit grid. It is not
derived from, and contains no outlines from, any licensed typeface.

## This repository

The code is Apache-2.0 (`LICENSE`). The visual identity is reserved rather than
open-sourced (`LICENSE-BRAND.md`); the two cover different files and the split
is deliberate.
