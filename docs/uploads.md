# Hosted uploads

Use `hosted/open-e2ee-logo-light.svg` or its dark variant for WorkOS and other uploads.
These files contain Public Sans outlines. PNG versions have a width of 1200 px.
Use the square mark for Google application branding.

The browser ICO contains 16, 32, and 48 px images. Touch icons use an opaque
background at 180, 192, and 512 px.
